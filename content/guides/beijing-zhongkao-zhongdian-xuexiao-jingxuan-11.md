## 一、答题卡填涂规范

### 选择题的填涂

选择题使用2B铅笔填涂。填涂不规范是常见的失分原因。

**填涂规范：**
1. 使用2B铅笔（不是HB铅笔，也不是自动铅笔）
2. 填涂要饱满，盖住整个方框
3. 修改时用橡皮擦干净，不留痕迹
4. 不能只画一道线，要填涂成方块

**常见错误：**
- 填涂太轻（机器扫描不出来）
- 填涂超出方框（可能被识别为两个答案）
- 修改不干净（旧答案残留导致误判）
- 漏填、错位（最致命的错误）

### 主观题的书写

主观题（填空题、解答题、作文）使用黑色签字笔书写。

**书写规范：**
1. 使用0.5mm黑色签字笔
2. 在规定的答题区域内作答
3. 字迹工整，不要连笔
4. 答案不能超出答题框（超出部分扫描不到）

### 答题卡上的个人信息

**开考后第一时间：**
1. 填写姓名、准考证号
2. 粘贴条形码（如果有）
3. 检查答题卡是否完好

## 二、各科的时间分配

### 语文（150分钟）

| 部分 | 建议用时 |
|------|---------|
| 基础知识 | 15分钟 |
| 古诗文阅读 | 20分钟 |
| 现代文阅读 | 30分钟 |
| 作文 | 45分钟 |
| 检查 | 10分钟 |

**关键：** 作文要留足时间。作文写不完，损失最大。

### 数学（120分钟）

| 部分 | 建议用时 |
|------|---------|
| 选择题 | 15分钟 |
| 填空题 | 15分钟 |
| 基础解答题 | 40分钟 |
| 压轴题 | 40分钟 |
| 检查 | 10分钟 |

**关键：** 基础题控制在70分钟内完成，留足时间给压轴题。

### 英语（笔试部分约90分钟）

| 部分 | 建议用时 |
|------|---------|
| 单选/完形 | 15分钟 |
| 阅读理解 | 30分钟 |
| 其他题型 | 25分钟 |
| 作文 | 15分钟 |
| 检查 | 5分钟 |

### 物理（90分钟）

| 部分 | 建议用时 |
|------|---------|
| 选择题 | 15分钟 |
| 填空题 | 15分钟 |
| 实验题 | 30分钟 |
| 计算题 | 25分钟 |
| 检查 | 5分钟 |

## 三、考场上的答题策略

### 策略一：先易后难

**原则：** 先做会做的题，再做不会的题。

**原因：**
- 保证基础分（把会做的题的分拿到手）
- 建立信心（做完会做的题，心态更稳）
- 合理利用时间（难题不恋战）

**操作：**
1. 遇到不会的题，先标记，跳过
2. 做完其他题后，回头攻克难题
3. 不要在一道题上卡超过5分钟

### 策略二：不留空白

**原则：** 主观题一定要写，不能空着。

**原因：**
- 写了就可能得分（按步骤给分、按要点给分）
- 空着一定是0分

**操作：**
- 数学题：写上能推出的步骤
- 语文作文：哪怕写不满，也要写完
- 物理题：写上公式、代入数据
- 英语作文：写够字数，用最简单的句子

### 策略三：认真审题

**原则：** 审题比做题更重要。

**审题要点：**
- 划出关键词（"错误的是""正确的是"等）
- 看清单位、范围、条件
- 理解题目的隐含条件

## 四、考试过程中的注意事项

### 开考前

1. 检查考试用品（准考证、身份证、文具）
2. 调整心态（深呼吸，告诉自己"我能行"）
3. 等待发卷（不要提前动笔）

### 发卷后

1. 先填个人信息（姓名、准考证号）
2. 粘贴条形码
3. 快速浏览试卷（了解整体结构，分配时间）
4. 从简单的题开始做

### 考试中

1. 控制时间（根据时间分配表，随时调整）
2. 遇到难题不慌（先跳过，回头再做）
3. 保持卷面整洁（不要乱涂乱画）
4. 注意书写规范（字迹清晰）

### 考试结束前

1. 预留5-10分钟检查
2. 检查答题卡（选择题是否填涂完整）
3. 检查主观题（有没有漏题）
4. 检查个人信息（姓名、准考证号）

## 五、常见问题与应对

### 问题一：时间不够用

**应对：**
- 合理分配时间（按时间分配表执行）
- 先易后难（保证基础分）
- 不会的题果断放弃（不要恋战）

### 问题二：答题卡涂错

**应对：**
- 填涂时看准题号（避免错位）
- 修改时擦干净（不留痕迹）
- 考试结束前检查一遍

### 问题三：紧张心慌

**应对：**
- 深呼吸（慢慢吸气，缓缓呼气）
- 暂停10秒（闭上眼，让自己冷静）
- 告诉自己"我复习得很充分"

### 问题四：遇到不会的题

**应对：**
- 不慌（不会的题大家都不会）
- 标记跳过（做完其他题再回头）
- 写步骤（能写多少写多少）

## 六、考前的最后准备

### 考试用品清单

- 准考证、身份证
- 2B铅笔（2支以上）
- 黑色签字笔（2支以上）
- 橡皮
- 直尺、三角板、圆规（数学物理）
- 手表（非智能）
- 透明笔袋

### 考试前一天的安排

1. 复习重点（不是全面复习，是看重点和错题）
2. 调整作息（早睡早起）
3. 准备考试用品
4. 熟悉考场路线

### 考试当天的安排

1. 吃好早餐（七分饱）
2. 提前到考场（留出缓冲时间）
3. 检查考试用品
4. 保持平常心

## 七、最后的提醒

**中考不仅考知识，也考心态、考规范、考细节。**

知识水平决定了你的上限，但心态、答题规范和时间管理决定了你是否能发挥出这个上限。

**认真对待每一次模拟考，把模拟考当成中考来考；中考时，把中考当成模拟考来做。** 这样到了真正的考场，你就能从容应对。
