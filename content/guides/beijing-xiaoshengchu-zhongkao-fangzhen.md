## 一、派位录取的规则

小升初派位的录取规则是：**志愿优先、按序检索**。

具体来说：
1. 系统先看第一志愿——如果第一志愿的学校还有名额，你被录取
2. 如果第一志愿的名额已满，看第二志愿
3. 如果第二志愿也满了，看第三志愿……以此类推

**关键理解：** 志愿顺序非常重要。第一志愿最优先，后面的志愿只有在前面志愿录不上时才会被检索。

## 二、志愿填报的核心原则

### 原则一：第一志愿填最想去的学校

第一志愿是你的"冲刺志愿"，填你最想去的学校。不用担心"够不够得着"——第一志愿录不上不影响后面的志愿。

**但要注意：** 不要填一个你根本不想去的学校作为第一志愿。一旦第一志愿录取，后面的志愿就作废了。

### 原则二：志愿之间要有梯度

相邻志愿之间应该有一定"差距"。如果所有志愿都填同一档次的学校，前面录不上，后面大概率也录不上。

**合理的梯度：**
```
第一志愿：冲刺（最想去的学校）
第二志愿：冲刺/稳妥（比第一志愿略低一档）
第三志愿：稳妥（大概率能进的学校）
第四志愿：稳妥/保底（比较保险的学校）
第五志愿：保底（肯定能进的学校）
```

### 原则三：必须填保底志愿

保底志愿是"最后的保险"。如果前面所有志愿都录不上，保底志愿能保证孩子有学上。

**保底志愿的选择标准：**
- 自己能够接受的学校
- 录取概率接近100%的学校
- 不要嫌"保底学校不好"——有学上比没学上强

## 三、各区的派位填报差异

### 海淀区（登记入学）

海淀区的登记入学可填1-10个志愿。

**填报策略：**
- 10个志愿全部填满
- 前3个填冲刺志愿
- 中间4个填稳妥志愿
- 最后3个填保底志愿

**注意：** 海淀区的登记入学竞争激烈，第一志愿的录取率通常只有20-40%。

### 西城区（全区派位）

西城区的全区派位可填1-5个志愿。

**填报策略：**
- 5个志愿全部填满
- 第一志愿填最想去的学校
- 后面志愿按梯度递减

### 东城区（一批次派位）

东城区的派位填报相对简单，志愿数量较少。

### 朝阳区（多校划片）

朝阳区的划片志愿填报与其他区不同，需要按照划片范围内的学校填报。

## 四、不同情况的填报策略

### 情况一：成绩拔尖的学生

**策略：** 大胆冲刺，志愿可以填得"高"一些。

```
第一志愿：人大附中/实验中学（冲刺）
第二志愿：首师大附中/八中（冲刺）
第三志愿：理工附中/十三中（稳妥）
第四志愿：二十中/十五中（稳妥）
第五志愿：普通示范校（保底）
```

### 情况二：成绩中等的学生

**策略：** 稳妥为主，志愿梯度合理。

```
第一志愿：二梯队头部（冲刺）
第二志愿：二梯队中游（稳妥）
第三志愿：二梯队尾部/三梯队头部（稳妥）
第四志愿：三梯队中游（保底）
第五志愿：三梯队尾部（保底）
```

### 情况三：成绩一般的学生

**策略：** 保底优先，确保有学上。

```
第一志愿：三梯队头部（冲刺）
第二志愿：三梯队中游（稳妥）
第三志愿：三梯队尾部（稳妥）
第四志愿：普通校（保底）
第五志愿：普通校（保底）
```

## 五、志愿填报的常见误区

### 误区一：不填保底志愿

"我觉得自己肯定能上XX学校，不用填保底。"——这是最危险的想法。派位有随机性，谁也不能保证100%录取。没有保底志愿，一旦前面的志愿都录不上，只能被统筹分配到最差的学校。

### 误区二：把不想去的学校填在前面

"我把XX学校填第一志愿，反正我肯定能上后面的。"——错！第一志愿一旦录取，后面的志愿全部作废。第一志愿必须是你真的想去的学校。

### 误区三：所有志愿填同一档次

"这几个学校都差不多，随便填吧。"——如果所有志愿都是同一档次，前面录不上，后面也录不上。志愿之间必须有梯度。

### 误区四：受他人影响填报

"大家都说XX学校好，我也填它。"——适合别人的学校不一定适合你。志愿填报要根据自己的实际情况（成绩、距离、需求）来决定。

## 六、最后的三点建议

1. **志愿填报前，先和孩子沟通**——了解孩子自己的想法，尊重孩子的意愿
2. **志愿填报后，不要频繁修改**——改来改去容易出错，确定好就不要再动了
3. **无论结果如何，保持平常心**——派位只是开始，初中三年才是关键
